# Negative Fixtures

Generated by `tools/generate_negative_cases.py`. Do not edit by hand.

Each `NEG-XXX/` directory is exactly **one mutation** of `../baseline/baseline.json`. For hash-stage cases the mutation applies to its sidecar instead. Each directory contains:

- `record.json` (or `record.json.hex`, see below)
- `record.json.sha256`, unless the case is `HASH_FILE_MISSING`
- `meta.json`, validated by `../../schemas/negative-fixture.schema.json`

`NEG-001` (`INVALID_UTF8`) is stored as `record.json.hex`, the lowercase hex of the exact bytes followed by LF. Its bytes are not valid UTF-8 text, and the only write path available to this repository accepts text only. The tools and tests decode it back to the exact bytes before auditing.

v0.1 has 27 fixtures, covering all 22 active reason codes. See `../../spec/rejection-reasons.md`.
