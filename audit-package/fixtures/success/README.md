# Success Fixtures (Illustrative)

These records are the **illustrative example records** from F.1 (`examples/*.json` at `runtime-contract-v1.0`). They are not logs of a real runtime execution. The records cannot carry an "illustrative" flag, because extra fields are forbidden, so the label lives here.

| File                  | Source (F.1)                              |
|-----------------------|-------------------------------------------|
| `verify-success.json` | `examples/verify-success.json` → `record` |
| `verify-fail.json`    | `examples/verify-fail.json` → `record`    |
| `replay-0002.json`    | `examples/replay.json` → `records[1]`     |
| `replay-0003.json`    | `examples/replay.json` → `records[2]` (also `../baseline/baseline.json`) |

`examples/replay.json` → `records[0]` is byte-identical to `verify-success.json` after conversion, so it is not repeated.

The files are generated by `tools/generate_success_fixtures.py`. It locates each record in the F.1 source with the lexeme-preserving scanner, removes whitespace outside strings (lexemes are copied verbatim), and appends one LF. Each file has a `.sha256` sidecar.
